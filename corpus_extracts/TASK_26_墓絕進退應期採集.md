#### 8.3.2 二維對照表（動爻狀態 × 變爻狀態）★

八格以**進神／退神自身之單一狀態**為變數；兩本皆以**動爻狀態 × 變爻狀態**兩個變數配對切分。逐項列出：

**《易冒》三法×二（行 291、293）**

| 名 | 動爻 | 變爻 | 判語 |
|---|---|---|---|
| **大進** | 旺相 | 日月 | 乘勢得位 |
| **不進** | 日月 | 空破 | 無階無路 |
| **不能進** | 破散 | 日月 | 我位既失，何以得前 |
| **實退** | 休囚 | 休囚 | 從流忘返 |
| **不退** | 日月 | 空破 | 我德克備 |
| **不及退** | 破散 | 日月 | 潰敗難收，咨嗟何及，安能退哉 |

**結構事實**：同一組（動爻＝日月／變爻＝空破）在進為「不進」、在退為「不退」；同一組（動爻＝破散／變爻＝日月）在進為「不能進」、在退為「不及退」。**六法實由三組配對而成，進退各取其一。**

**《增刪卜易》四法×二（行 2542–2551）**

| # | 動爻 | 變爻 | 判語 |
|---|---|---|---|
| 進一 | 旺相 | 旺相 | 乘勢而**進** |
| 進二 | 休囚 | 休囚 | **待時**而進 |
| 進三 | 動爻變爻**有一**值衰 | **待旺相之日**而進 | |
| 進四 | 動爻變爻**有一**值空破 | **待填實之日**而進 | |
| 退一 | 旺相 | 旺相（或有日月動爻生扶） | 占近事得時而**不退** |
| 退二 | 休囚 | 休囚 | **及時**而退 |
| 退三 | 動爻變爻**有一**旺相 | **待休囚之時**而退 | |
| 退四 | 動爻變爻**有一**逢空破 | **待填實之日**而退 | |

**★ 兩本之結構差異三項（只陳述，不判孰是）**：

1. **項數不等**：易冒三法×二＝六；增刪四法×二＝八。
2. **第三、四法不再區分動爻與變爻**：增刪作「動爻變爻**有一**而值衰／值空破」，即**兩個變數併為一個**。易冒六法則每法皆同時指定動爻與變爻。
3. **★ 輸出形態不同**：易冒之判語為**成否之判定**（進／不進／不能進；實退／不退／不及退）；增刪之判語為**應期**（待時、待旺相之日、待填實之日、及時、待休囚之時）。即**增刪把易冒之「能否」改寫為「何時」**。

```text
1701: 头以生木也，即以吉断。如震卦化乾卦，震木变乾金谓之化克，金回头以克木也，即以凶推。
1702: 又有化克而不克者，不可不知。如兑金变震木，谓之化去。正卦为我，我去克他，不为凶也。此则谓
1703: 之化克而不克也。如震木变兑金，谓之化来，他来克我，回头之克，即为凶兆，诸占大凶。
```

#### 《增刪卜易》進神四法、退神四法（2541–2551）

```text
2541: 此乃动日月而化空，岂可谓之不进耶？
2542: 野鹤曰：夫进神之法有四。
2543:  动旺相而化旺相，乘势而进者，一也。
2544:  动休囚而化休囚，待时而进者，二也。
2545:  动爻变爻有一而值衰，待旺相之日而进者，三也。
2546:  动爻变爻有一而值空破，待填实之日而进者，四也。
2547: 退神之法亦有四。
2548:  动旺相而化旺相，或有日月动爻生扶，占近事得时而不退者，一也。
2549:  动休囚而化休囚，及时而退者，二也。
2550:  动爻变爻有一而旺相，待休囚之时而退者，三也。
2551:  动爻变爻有一逢空破，待填实之日而退者，四也。
```
