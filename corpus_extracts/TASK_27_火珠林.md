## 八、軸向判定材料（六種標記）

**標記定義**（前四項依 S3；`concept_absent` 為 2026-09-14 第一次裁決新增；`explicit_exclusion` 為同日第二次裁決新增）：

| 標記 | 定義 |
|---|---|
| `maps_cleanly` | 該分類可直接對應某一格 |
| `maps_partially` | 部分重疊，但範圍不同 |
| `different_axis` | 有立場，但以不同軸向表述 |
| `no_equivalent` | 該格在此書中無對應內容（**概念存在，書中沒講**） |
| `concept_absent` | 該書體系中**根本無此概念**（如《火珠林》無「元神」一詞） |
| **`explicit_exclusion`** | **該書明文排除某概念或角色，非未曾有此概念**（如《火珠林》行 126「兄弟是破財之人，不為主、不為輔，何必看也」） |

**另兩種屬決策表狀態（S8），非本表所用，列出以資分辨**：`not_addressed`（讀過，它沒有講）、`not_collected`（我們未讀過）、`category_negated`（明文否定某**狀態**成立，如野鶴「余從來不言散」）。

**六者之分界**：

| 對比 | 分界 |
|---|---|
| `no_equivalent` vs `concept_absent` | 前者「有此概念，書中沒講」；後者「書中連此概念都沒有」 |
| `concept_absent` vs `explicit_exclusion` | 前者「未曾有此概念」；後者「**有想過而拒絕**」—— 須有明文排除之語為據 |
| `explicit_exclusion` vs `category_negated` | 前者排除一個**角色**（第三位不看）；後者否定一個**狀態**（散不成立） |
| `not_addressed` vs `not_collected` | 前者已讀而書中無；後者未讀 |

### 8.2 C1 表為何標 `different_axis` —— 逐項原文

C1 五格繫於**衰旺軸**（旺相／有氣／臨日月／休囚 之爻遇沖）。本書論「沖」與「散」各有其軸，**與衰旺無涉**：

**（一）「散」之成因不是沖，是獨發與世動**
```text
262: 子孙独发，为退为散；
752: 凡占脱事散忧，要子孙旺相出现，或子孙独发，世爻动亦自散。
```

**（二）「沖散」連用之唯一二處，所散者非用爻，且結果為吉**
```text
758: ……若占论何日出禁？须要得日辰冲散六害，方出。如世爻持未，得丑爻动，或日辰是丑，当是丑日出狱也。
1267: ……只有年时及化离丑未四屋零屋冲散复成之象……
```

**（三）「沖」之效果被表述為「阻」「不在」「便歸」「不成」，非「散」**
```text
523: ……逢冲，将入手有阻。
493: 谒见，用支出现旺相不动，在家；若空、冲、散，不在。
300: 占自身，或占父在外欲回家，看世又绝墓日动身。又看世持什爻，待日辰冲便归。
431: 出现忌日冲，世动，男不肯，应动，女生疑。
```
**行 493 為全書唯一將「空」「沖」「散」三字並列者，且與「旺相不動」相對** —— 惟其為**四項並列之判**（旺相不動＝在家；空／沖／散＝不在），**非「旺相之爻遇沖如何」**。
