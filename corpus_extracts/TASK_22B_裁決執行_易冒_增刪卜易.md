
### 1.3 606 是否為審計計數有誤

**否。** TASK_22 §2.5.6 之原文為：

> **606 行（去重後）**：`<!-- page N -->` HTML 註釋 **237 行**；版心頁碼行 `·NNN·` **227 行**；目錄點線行（`……N`）**142 行**。

### 3.2 三類之判別依據（逐類，可機械驗證）

**P1 頁碼註解 237 行**
- 式樣：`^<!-- page N -->$`，整行僅此註釋。
- 依據：HTML 註釋語法，古籍刻本不可能有；編號 1–237 連續，與檔內第 3 行自述「全书共 237 页」逐一對應，即紙本頁面邊界之標記。

**P2 頁首 114 行**
- 式樣：`^增删卜易 野鹤老人著 ·N·$`，整行為此無他字。
- 依據：書名＋著者＋頁碼之固定版心格式；N **全為奇數頁**。為紙本版心（書口）文字。
- 例：`292: 增删卜易 野鹤老人著 ·1·`　`350: 增删卜易 野鹤老人著 ·3·`

**P3 頁碼＋章題 113 行**
- 式樣：`^·N· <章題>$`，整行為此。
- 依據：N **全為偶數頁**；章題共 71 種，**全部與檔內既有章題重複**（「增删《黄金策千金赋》第三十四」重出 13 次、「天时章第三十五」9 次、「八宫章第三」4 次、「终身财福章第三十七」4 次），即版心葉眉標目而非正文篇題。
- 例：`322: ·2· 卦象图章第二`　`392: ·4· 八宫章第三`

**114 ＋ 113 ＝ 227，與 TASK_22 所報之 `·NNN·` 227 行相符。**
