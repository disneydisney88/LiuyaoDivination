# 端到端文字快照

`cases/` 是十二則固定、可重跑的卦例定義；`golden/` 是其完整使用者文字快照。執行 `python tools/snapshot.py --check` 會逐字比較正文；有差異時，差異可能是修復，亦可能是回歸，須人手判斷。更新 golden 必須執行 `python tools/snapshot.py --regenerate-golden` 並輸入指定確認字串。

## 本機制之邊界

文字快照與黑名單可捕捉：

- 任何導致文字輸出改變之 regression
- 已知教義詞之洩漏
- 內部標記與資料結構之洩漏
- 頁面空白、載入失敗

**捕捉不到：**

- **首次出現之新型越界** —— 若某層輸出了一個不在黑名單上的教義性判斷，快照只會把它當成正常內容存入 golden
- **語意矛盾** —— 兩段文字各自合格，但並排出現時自相矛盾
- **格位設計之偏向** —— 表格切法是否偏向某一家（C14），無法由機器判定
- **材料是否完整** —— 節錄不全導致標記偏低，機器無從知曉

**故人手實測不可省。** 本機制之作用是讓人不必重複檢查已知問題，把注意力留給上述四類。
